# 爬虫桌宠

这是一个 Windows 透明桌宠：灰白色骨骼爬虫会在桌面壁纸层追随全局鼠标，普通软件窗口会遮住它，桌面操作不受影响。

兼容 Wallpaper Engine：桌宠会排列在 Wallpaper Engine 动态壁纸之上、普通应用窗口之下，不会暂停、替换或修改动态壁纸。虫子经过桌面图标时会显示在图标上方，但仍然完全点击穿透。

## 直接运行

双击 `dist\ReptileDesktopPet.exe`。程序不会显示主窗口，运行后可直接回到桌面并移动鼠标观察。

右键任务栏通知区域中的桌宠图标，可以：

- 暂停或继续动画
- 设置腿对数（可自由输入 1～50，保存后立即生效并永久记忆）
- 开启或关闭开机自启
- 退出程序

双击托盘图标也可以暂停或继续。

未保存腿对数时，程序每次启动会随机生成 1～12 对腿；通过托盘保存后，后续启动会固定使用该数量。设置保存在当前 Windows 用户的注册表 `HKEY_CURRENT_USER\Software\ReptileDesktopPet` 下。

在桌面图标以外的空白处单击左键，可以让桌宠停止追踪；再次单击桌面空白处即可继续。点击文件、快捷方式、任务栏、窗口或桌宠自身不会切换追踪状态。

鼠标停止后，桌宠会完成当前迈步、消除转向惯性并让脊柱回正；靠近光标并落稳后会进入静止状态，不再随机扭动。鼠标再次移动时自动唤醒。静止期间不会持续重绘，可显著降低常驻 CPU 占用。

## 多显示器

程序会枚举所有已连接显示器，并为每块屏幕创建独立透明渲染层；鼠标和身体节点使用统一的虚拟桌面坐标，因此能够跨屏追随。显示器连接、断开或分辨率变化后，渲染层会自动重建。

## 本地重新编译

在项目目录打开 PowerShell，运行：

```powershell
.\build.ps1
```

生成结果会直接覆盖 `dist\ReptileDesktopPet.exe`。当前构建使用 Windows 自带的 .NET Framework 4.8 编译器和运行库，不需要安装 Python、Node.js 或额外 SDK。

## 动作模型来源

关节、逆向运动学和随机爬行动物结构移植自 MacSearlas 的 [Creepy Crawly Kinematics](https://gist.github.com/botmad/581a3abcb3d0fd77e415629e1dc703ba)，并针对 Windows 桌面、多显示器、Wallpaper Engine 和固定时间步进行了改写。
